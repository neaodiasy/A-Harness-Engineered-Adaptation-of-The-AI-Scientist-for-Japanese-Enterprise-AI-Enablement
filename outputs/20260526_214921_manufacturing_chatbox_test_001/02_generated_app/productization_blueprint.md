# Productization Blueprint: Approval Review Console

- Maturity target: `enterprise_software_mvp`
- Source opportunity: `Maintenance Knowledge Chatbox`
- Primary job: Review a request against policy, collect evidence, and produce a controlled approval packet.

## Required Enterprise Capabilities

- case_queue
- structured_intake_form
- runtime_live_web_evidence_search
- domain_tool_panel
- candidate_or_result_comparison
- editable_business_draft
- human_approval_packet
- activity_log
- audit_trace
- error_and_loading_states

## Visual Quality Contract

- sidebar navigation
- case queue
- workbench panels
- candidate or result table
- evidence source list with live-search markers
- approval actions
- activity log
- debug JSON secondary only
- responsive KPI cards using auto-fit minmax grid
- tablet and mobile breakpoints
- safe wrapping for long labels and model outputs
- no horizontal page overflow
